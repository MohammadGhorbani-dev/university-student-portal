# University Student Portal

> A modern, responsive university student portal built with React and Firebase.

## Live Demo

https://university-portal-demo.web.app

## Overview

University Student Portal is a role-based web application designed to provide
students and university staff with a centralized platform for managing
academic activities and university services.

## Features

### Student
- Dashboard
- Course registration
- Course dropping
- Weekly schedule
- Reservations
- Reservation cancellation
- Announcements
- Requests
- Support tickets
- Profile management
- Password reset
- Help & FAQ

### Admin & Staff
- Dashboard
- Course management
- Announcement management
- Reservation management
- Request management
- Support management
- User management
- Administrative statistics

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting

## Security

- Firebase Authentication
- Role-based access control
- Firestore Security Rules
- Student data isolation
- Protected routes
- Protected academic fields
- Transaction-based course registration and reservations

## UI

- Responsive design
- RTL support
- Persian localization
- Light / Dark mode
- Accessible interactive components
